常见问题解答 (FAQ)#

+
完全不需要！直接前往官网注册账号只需要填写常用邮箱和密码，没有任何邀请码门槛。

输入邀请码可以享受打折吗？#

不能。邀请码（Invite Code）只负责验证你的购买资格；想要享受价格折扣，需要在结算页面的 Promotional Code 输入框填入优惠码。
